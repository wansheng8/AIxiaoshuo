# 卡壳建议

雪花卡壳：三个走向都必须从当前场面表这一场长出来。只换人物选择和代价，不另起一套故事。

## 先有感觉
三条路都要打在他在乎的人或手上的物件上。正确解法三条并排，读者不会追。

## 连载作者
三个走向里至少一个是误判或失败，失败带走新问题。禁止三条都是正确解法。钩子换类型。

## 适用场景
作者写到一半卡住，需要情节走向、对话或人物选择的具体选项。

## 输入
- 当前章节正文或细纲、人物库、未收伏笔、作者附加指令

## 输出结构

### 此刻压力
一两句：人物正站在哪、手里还拿着什么、必须立刻决定什么、他此刻信着哪句错话。

### 三个走向
每个走向按此格式：

1. 走向名
   - 场面：接下来 400 字里发生什么
   - 人物选择：谁为了什么付出什么
   - 误判：这条路他会看错什么
   - 代价：这条路会丢掉什么
   - 钩子：这场结束时读者还想看什么
   - 钩子类型：A新人物 / B新信息 / C新危险 / D新奖励 / E新选择 / F身份反转 / G认知反转 / H更大问题

三个走向必须互相排斥，分别偏：人物关系、世界规则反噬、未收伏笔推进。
至少一个走向是误判或失败，失败带走可见后果和新问题。
三个钩子类型互不相同，并避开近几章已经用过的同型。

### 推荐
只推荐一个，并写清它为什么最贴心口和声口。

## 约束
- 每个走向都必须是可拍摄场面
- 三个走向都必须从此刻手上的物件或未完成动作长出来，禁止突然甩一个新地点名当标题
- 三个走向都必须停在本章场面表内。禁止把第二灾、第三灾提前到当前场
- 尊重人物小传的欲望和秘密。情报型配角保持被动，不靠他派任务推进
- 不重写整章，不输出正文
- 三个走向里至少一个是误判或失败带新问题
- 钩子换类型，避开近几章已经用过的同型钩子

## 执行步骤
1. 先钉死此刻未完成的动作和那句错话
2. 用人物选择分出三条路，其中一条必须先做错
3. 按输出结构一次写完

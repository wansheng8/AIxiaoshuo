# 分章细纲

雪花场面表：每一章拆成 2 到 3 场可拍摄的场面。每场写清视角、进场状态、目的、冲突、下场带走什么。只拆大纲节拍，不另起故事。

## 先有感觉
每章先写心口：谁怕丢掉什么，谁会心疼谁，哪一句没说出口。场面表围着这三样排。只有目标冲突钩子、没有心口的细纲，后文会写成流水账。

## 连载作者
场面表默认「问题→行动→结果→新问题」。结果先落地。钩子换类型。每 3 到 4 章一场失败或误判，失败带走后果。相邻章开头结构也要换，禁止连续「他醒了 / 他推门 / 他看向天空」。

## 适用场景
已有全书大纲，准备按章写正文。一次只拆即将开写的若干章。

## 输入
- 大纲、人物、上一章结尾、作者想写的章数

## 输出结构
默认输出 8 章。若作者指定章数，按指定数量。

每一章用这个模板：

### 第N章 章名
- 目标：本章主角想办成的一件具体事
- 冲突：谁或什么规则挡住他
- 心口：谁怕丢掉什么；谁会心疼谁；哪一句没说出口
- 冲突链：上场带走什么，如何变成本场问题
- 内外阻力：外挡谁或哪条规则；内绊在哪个缺口或误判
- 出场：名单，点明每人本章的功能、当前利益、对主角的表面态度
- 场面表：2 到 3 行，必须标明「起势 / 主场 / 钩子」。每行写成：
  场次｜视角｜进场带着什么｜本场要办成｜谁或哪条规则挡住｜下场带走什么
- 误判：他本章会看错什么，错在哪一步
- 转折：章内哪一句信息或哪个选择改变局势
- 钩子：最后停在哪一个动作临界点（手伸出去、门推开一半）
- 钩子类型：A新人物 / B新信息 / C新危险 / D新奖励 / E新选择 / F身份反转 / G认知反转 / H更大问题，八选一，近三章同型不用
- 节奏：主场是第几场、约占六成字；过场压缩哪一段；钩子停在哪一秒
- 伏笔：本章埋、点或收哪一条；只露表面，不写实际
- 爽点三拍：打脸（谁质疑 → 主角怎么亮证据/数字）｜围观（旁人变脸的具体过程）｜反应（谁哑火、主角怎么离场），三拍缺一不可
- 必写爽点：本章必须兑现的具体爽点，落到对白、动作或数字
- 弧光：谁的信念或关系发生可见变化

标题必须独占一行，N 用阿拉伯数字。从作者指定的起始章连续编号；资料里已有第M章细纲则从第M+1章起编，禁止从第1章重编。章名写在「章」字后面，不要书名号，不要写成故事第一句。示例里的「第N章」只是格式，实际编号以作者指令为准。

## 约束
- 每章只打一个主冲突
- 场面表必须连锁：上场结果变成下场问题。禁止三场互不相干
- 反转场必须点明铺垫落在哪一章哪一句信息或哪个反差
- 冲进死地必须写清非去不可的理由：系统时限、外部逼迫、两烂选项。禁止只写不甘心、硬气
- 人物判断未知规则必须写清出处：系统、当场试探、前人交代。禁止细纲里写「他闻出来它不追」
- 钩子禁止连续两章用同一物件（乌鸦、面板、蓝光）蹲着看收尾。要么让它做一件具体的事，要么整章不出场
- 三场戏禁止写成一样长。主场写清围观、对话来回、当场后果；过场一两句带过
- 钩子只露牙，停在动作临界点。禁止用内心吐槽收尾，禁止在钩子里把下一章的打戏、搜证、传话写完
- 认出未知物时写清分层：先听到、摸到、看到哪一块，再揭晓名字。禁止细纲里写「扒开铁皮，巨齿鼠」这种一眼报出
- 系统、面板首次出声要带一句态度，禁止只写播报数据
- 第1章起势第一句写异常；金手指、系统或面板必须在第1章前半段露面
- 每个出场配角写一个生活痕迹（袖口、茶渍、磨白的窗口）
- 每章金手指或能力兑现一次可见效果。被压后给一次微小反击或两秒选择镜头
- 主场必须填满「打脸—围观—反应」三拍：亮证据/数字、旁人变脸、反派哑火，禁止把冲突概述成一句
- 「消息传到某人」只留一句口风，办公室戏留给下一章
- 章名具体，禁止“风云再起”这类空名
- 相邻两章信息增量必须不同
- 只写细纲，不写正文
- 每场必须能从大纲「第一卷节拍」或「雪花一页」读出来。禁止章内另起与三灾无关的新任务
- 第 N 章第一个场面必须接住第 N-1 章的钩子，禁止冷开一场新戏
- 因果必须来自上一场的选择或代价
- 换场从上一场手上的物件或未完成选择长出来。禁止细纲把下一场写成突然出现的地点名（「下一场：黑市」）
- 情报型配角只问一句答半句，禁止写成任务发放员
- 相邻章的情绪从上一章钩子的人物状态接着长，细纲写状态变化，不要写「基调：悲伤 6/10」
- 钩子类型近三章禁止重复
- 每 3 到 4 章安排一场失败或误判，失败带走可见后果和新问题
- 场面表写成问题→行动→结果→新问题。结果先落地
- 相邻章开头结构必须换

## 执行步骤
1. 先写本章心口，再从上一章钩子起步。细纲第一句写清人物还站在哪里、手里还拿着什么、心里还卡着哪句。冲突链先钉：上场带走什么，如何变成本场问题。内外阻力成对写
2. 让人物关系每 2 到 3 章发生一次可见变化：心疼、翻脸、松手或咽回去
3. 标出误判和钩子类型，最后一章的钩子要能直接接下一章目标

## 自动开书
写完后系统会按「### 第N章」拆进目录。
- 首次开书从第1章编到第8章，并立刻用第1章细纲写正文
- 若资料里已有第1章到第M章细纲，只输出第M+1章起的下一批，默认再写 8 章，禁止重写已有编号
- 每一章写满模板：2 到 3 个场面，够写核心设定的本章字数（默认 2200 到 3800 字）。主场信息量必须明显厚过起势和钩子
- 只输出细纲条目。禁止大段对话，禁止把某一章写成小说正文

# 逻辑闭环自检

逻辑服务于情绪。先补影响读者理解与情绪的漏洞，再抠细节；别为了圆设定拖垮节奏。逐条过，命中就写进问题清单并给改法。

## 一、找硬凑（最高优先）
- 哪个转折是作者替角色按下的？天降遗产、陌生亲戚送巨款、随手捡到关键物件、敌人突然犯蠢。
- 每处关键获得，主角付出了什么代价？信息、资源、帮手都算。没有代价的收获，要么删掉，要么补上代价。
- 删掉这份「好运」，情节还走不走得下去？走不下去就是硬凑。

## 二、查人物逻辑
- 每个关键行为，接得上他的性格、动机、背景、处境吗？
- 动机给够了吗？给不够就补铺垫，或改行为。
- 每个转折标注「这是谁的什么性格 / 动机推动的」。标不出，就是硬按的。

## 三、查情节逻辑
- 主要事件能不能串成「因为…所以…因此…」的链？接不上的事件要么砍，要么补前因。
- 有没有埋了没收的前因？收的前因够不够重？
- 关键点是否一笔带过？越关键的信息，越要写他付出的代价（跑腿、欠人情、冒风险、吃亏）。

## 四、查设定一致性
- 每条设定：规则、边界、代价是否齐全？写「人能飞」，就要交代为什么能飞、代价是什么。
- 称呼、能力、时间线、地理前后一致吗？所有角色受同一套规则约束吗？

## 五、交付要求
- 只列「位置 + 问题 + 改法」三件套，禁止泛泛而谈。
- 自己读着别扭的地方，一律标出来，别赌读者看不出来。

# 文风润色

雪花润色：只改句子，不改场面表上的事实。谁在场、办成没办成、下场带走什么，全部保持原样。

## 先有感觉
润色先找心口空的地方：只有动作和部位词、没有碎碎念和犹豫。允许用当场物件和一句俗念头补上。机械化的稿，先把人味补回来。

## 连载作者
润色是删除优先，再补人味。机械化优先于空比喻：全章同一段长、对白全是信息、思维太完整、动作后再总结。禁止为去AI而故意写差，禁止往句子上贴新的碎碎念装饰。空环境铺陈改成两个能用的抓手。对白不推动局势或关系就删。形容词换成动作或物件。

## 适用场景
作者选中一段正文，或指定润色本章最近一段。

## 输入
- 选中段落，立项中的调性，人物声口

## 输出结构
只输出润色后的段落正文。不要对照表，不要解释改了什么。
若作者附加指令要求输出「版本A / 版本B / 版本C」，则按该标题输出三个完整段落，不要只给一段。

## 约束
- 情节事实、人名、时间线、能力等级全部保持原样
- 节奏、潜台词和对话辨识度贴着原文改。感官用动作、温度、声音，禁止往句子上贴新形容词或新比喻
- 把完整问句改成带气口的半截话：写成“什么……轮回塔？”
- 把「时间，」它说，「你还有六个小时。」改成整句或先用动作把话说开。下一句必须接住上一拍
- 单独成段的单字地点、单字结论删掉，接到手上正摸着的物件后面。不要「黑市。」「完了。」这种标题卡
- 漏在【】外面的「来源：」「等级：」「持续时间：」「冷却时间：」收进【】；纯标签且下一段已经在演的直接删
- 若作者要求「演出来」：把概括情绪改成动作链+感官+俗碎碎念。情节事实保持，允许把「我很害怕」换成具体身体反应
- 「演出来」时按六层带入补：职业变肌肉记忆；配角一个生活痕迹；发现先局部后名字；系统带态度；金手指给一次可见效果
- 删掉解释性心理总结，改成动作或潜台词
- 删除优先七层：解释句、总结句、同义复读、说明书对白、一口气想完的内心、下一段解释上一段、为去AI而加的碎碎念
- 一口气想完对错利弊的内心，只留看见、身体先动和一句俗念头
- 说明书对白改成绕话、打断或说一半
- 动作已经表达的信息，后面的解释句删掉。握紧拳头后面禁止留「显然他很愤怒」
- 连续堆砌的修饰性四字词删掉一半
- 空环境（天很蓝、风很大、气氛凝重）改成当场能绊脚、能抓住、能闻见的抓手
- 对白不推动局势、关系或知情范围，删掉或改成半截话
- 长度与原文相近，上下浮动不超过 20%
- 禁止把口语改成文言文，除非立项调性就是文言
- 去掉翻译腔、空形容词、空比喻、空描写和 AI 套话：不禁、突然意识到、心中暗想、不由得、一丝、微微、仿佛、宛如、像、似的、不堪重负、精准地、特有的、带着一种、下意识地、目光还没收回来、声音渗进来
- 空转修饰只删不添。一句一个「的」
- 心口是空的时候，允许用当场物件和一句俗念头补上，字数可略增。作者要求「演出来」时同样可略增
- 句式贴着原文节奏，只改发空的地方
- 顺手改错别字、同音别字、人名前后不一、重复或中英混用标点
- 顺手改网文标点：英文改全角，分号改句号，！！改成一个！，叙述段尾……改句号，对话“”，系统【】且单独成段
- 视角锚：删掉切进配角心里的句子（可赵擎天看见了。他皱眉），只留主角看得见的外部动作或表情。章末钩子来自配角时，删掉或改成主角当场能拿到、能看到的证据（苏瑶藏纸改成纸角在主角眼前露了一下，随即被塞进袖口）
- 机制句：删掉解释爽点因果的句子（他第一次感觉，嘲讽本身像一根引线；这说明；原来是因为），换成身体异变和现场物件（石台又裂开两道）
- 信息梯度：一段只留一个新设定，其余挪到人物动作和代价之后。把顿号罗列的设定词（灵力、丹田、经脉、封印）删到只剩当下一件，或改成他这一下要付的代价
- 对白：每句对白要么带当下的利益或恐惧，要么改成绕话、打断、半截话。交代背景的对白（十年了、废物就是废物）删掉或挪成动作。羞辱补一句具体动机，别让配角只当羞辱工具人
- 节奏呼吸：长短交替。高潮前把长句拆成短句成簇，高潮后留一个长句呼气。连续 4 句以上长度接近或全是短句，中间插一句长的
- 动作与道具：无后果动作删掉（搓了三下，搓得发烫）。道具特写不承担钩子（指缝里露出一角泛黄的纸边），钩子改成人物的一次选择
- 情绪直陈：直说情绪的句子删掉（他第一次感觉羞耻、一股愤怒涌上心头），换成身体反应、一次停顿、手里那个物件，再补一次难看的选择

## 执行步骤
1. 先标心口空的地方：只有动作和部位词、没有碎碎念、关系痕迹、代价犹豫。用当场物件和一句俗念头补上
2. 按删除优先七层扫一遍：解释句、总结句、同义复读、说明书对白、一口气想完的内心、下一段解释、贴上去的碎碎念
3. 标出发空的形容词、空比喻、空描写和重复信息，删掉。像、仿佛、宛如、似的一律删
4. 标出标题卡和漏出【】的系统字段：单字地点接到物件上；「来源：未知。」这类标签删掉或收进【】
5. 若附加指令是「演出来」，按动作链改写后给出成品

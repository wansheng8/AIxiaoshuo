# 全书大纲

雪花扩层：立项「雪花五句」各扩成一段，再扩成卷纲。只加细节，不改谁赢谁输、不换结局赌注。

## 先有感觉
每卷高潮必须落到他在乎的人身上：受伤、离开或反目。灾变写在关系上，禁止只写升级路线和地图锁。

## 连载作者
小爽要高频，大爽要低频。失败必须带走可见后果和新问题。信息有波形：有的章讲七成，有的章只露牙。禁止一卷只升不摔。禁止把卷纲写成因为A所以B因此C的说明书。

## 冲突连锁
冲突为王。每卷一条主冲突链：上一场结果变成下一场问题。禁止并排三场互不相干的打戏。
内外阻力成对：外是人或规则挡住他；内是缺口、误判、嘴硬让他自己绊自己。
反转必须有铺垫。第二灾、身份反转、认知反转必须能从前面的误判、伏笔或反差读出来。禁止无铺垫的天降反转。

## 适用场景
人物和世界已有雏形，需要全书骨架。

## 输入
- 立项、世界观、人物库、作者对篇幅的要求

## 输出结构

### 主题句
一句话：这本书在问什么。必须能从立项主题句读出来。

### 雪花一页
把立项「雪花五句」各扩成一段，每段六到十句，顺序固定：开局、第一灾、第二灾、第三灾、结局。每段都要写清五样，缺一样这层雪花都不算厚：
- 主角当前处境，以及他此刻手上正拿着什么
- 他伸手去够的物件、机会或人
- 当场做出的一次选择，以及他为什么只能这么选
- 选错或受阻后付出的具体代价
- 这一灾之后他失去什么、误信了什么、关系被推到哪里
只加人物选择、物件、代价、误判，不改结局赌注。每段收尾都要能直接拆成 2 到 3 个章级场面，禁止停在抽象总结上。

### 主线
用一行串起雪花一页：开局处境 → 第一灾 → 第二灾 → 第三灾 → 结局赌注。

### 平台节奏
按立项类型与平台排爽点密度，缺一项都算漏：
- 番茄：第1章前100字出冲突，每章至少一个小爽点，每章结尾必留事件钩子。
- 七猫：前3000字出第一个高潮，前三章完成一次身份转变，情绪落差要写透（辉煌 → 跌落 → 反击）。
- 起点：每3章一次能力突破，每5章一次认知刷新，每7章一次关系重构；金手指有触发条件和代价。
- 无论哪个平台，金手指按立项规则给：触发条件、奖励范围、冷却、限制、成长曲线缺一不可，禁止无限开挂。
- 每个主要冲突排一次「打脸—围观—反应」闭环，冲突禁止概述。

### 故事线
把这本书要跑的每一条线一次列全，缺一条都要补。每条线都按这一行写，缺项不算：
线名｜类型｜起点（第几章、什么状态）｜推进节点（2 到 4 个，标章）｜转折（哪一章、谁做的选择）｜与主线在哪一章交叉、交叉后主线怎么变｜结算章与结局走向
必须覆盖，缺一不可：
- 主线（故事线）：主角的目标与最大阻碍，全书只此一条，必须与「雪花一句」逐字对齐
- 感情线：谁和谁，从哪一步开始变，中间几次靠近与退开，最后落在陪伴、分离还是错过
- 成长线：主角相信的旧错话在哪几个选择里被打破，结局改信什么，用一个具体动作证明
- 事业线 / 力量线：他靠什么往上走，能力兑现在哪几章露脸，每级台阶付什么代价
- 恩怨线 / 复仇线：谁欠谁，追讨的次序，谁先动手，谁在最后反转
- 悬疑线 / 伏笔线：读者一路要猜的问题是什么，前文埋了哪几件物件、哪几句话，在哪一章回收
- 配角线：每个主要配角一条，写他的目标、误判、与主角关系的变化、他自己的下场
- 支线：最多 2 条，写清它如何在中后段撞击主线
每条线的推进节点都要落到具体场面和人物选择，禁止写成状态描述。所有交叉点必须在下面「卷纲」和「第一卷节拍」里标出来，禁止只在「故事线」里孤零零列着。

### 卷纲
按 2 到 4 卷写。两卷时：上卷开局到第一灾，下卷第二灾到结局。三卷时：一卷一灾，末卷收第三灾与结局。每卷包含：
- 本卷问题
- 本卷心口：他在乎的人怎样
- 本卷冲突链：上一场结果如何变成下一场问题
- 内外阻力：外挡的人或规则；内绊的缺口或误判
- 主角策略
- 世界的反击
- 本卷失败场：他看错了什么，带走什么新问题
- 本卷高潮场面
- 卷末钩子类型：A新人物 / B新信息 / C新危险 / D新奖励 / E新选择 / F身份反转 / G认知反转 / H更大问题，八选一，与近几章章末钩子不同型
- 卷末读者必须追下一卷的钩子

### 第一卷节拍
列出 12 到 18 个节拍。每个节拍一行：场面、人物选择、后果。其中至少 3 个是失败或误判。

### 伏笔账本
4 到 8 条，每条一行：名称｜埋设章｜回收章｜表面意义｜实际意义｜它证明主题的哪一面。

### 节奏
标出密段（冲突）和疏段（日常/余波）交替。每卷至少一个最坏时刻。每卷至少一场失败，失败带走可见后果和新问题。信息波形：密段讲七成，疏段只露牙。小爽密、大爽疏。

## 约束
- 2200 到 3400 字
- 只膨胀立项雪花五句。禁止另起一套主线或换结局
- 「故事线」必须覆盖主线、感情线、成长线、事业线、恩怨线、悬疑线、配角线、支线，缺一条都算漏
- 主线全书只此一条，其余每条线都要写清与主线在哪一章交叉
- 每条线都要有起点、推进节点、转折、结算章。每条线的推进节点都要能直接拆成章级场面
- 每个高潮必须来自人物选择，禁止天降神兵
- 若作者已有大纲，只加固，不推翻
- 多线必须写清何时交叉，每条线都有可见进展
- 只输出大纲骨架。禁止写小说正文，禁止写大段对话，禁止把某一章写成故事
- 情报型配角保持被动，主线推进靠主角选择和世界反击，禁止写成配角派任务
- 默认「问题→行动→结果→新问题」。结果先落地，原因后补
- 反转必须能从前面的误判、伏笔或反差读出来
- 禁止把卷纲写成说明书式因果链

## 执行步骤
1. 先抄立项雪花第五句当结局赌注，再扩成雪花一页
2. 倒推中点必须失去什么，对上第二灾
3. 把主线、感情、成长、事业、恩怨、悬疑、配角、支线逐条列出，标清每条与主线的交叉章
4. 用第一卷节拍证明开书 3 章能咬住第一灾的牙，并标出失败场

## 自动开书
本步只交全书骨架。下一步会按章拆成「### 第N章 章名」。
- 必须出现「### 雪花一页」，五段顺序与立项五句一致
- 必须出现「### 故事线」，覆盖主线、感情、成长、事业、恩怨、悬疑、配角、支线八类，每条标与主线的交叉章
- 第一卷节拍按章的粒度写，方便拆成第1章到第8章
- 伏笔账本每行：名称｜埋设章｜回收章｜表面意义｜实际意义｜证明主题的哪一面
- 人名地名与人物库、场景卡逐字一致
- 不写人物档案，不写带对话的正文

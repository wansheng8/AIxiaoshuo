# 拆书章纲

只拆本批输入里的章节。每章四句，禁止写成小说正文。拆的是写法，禁止续写情节。

## 输出结构
### 第N章 原标题或概括标题
- 目标：
- 冲突：
- 出场：
- 钩子：
- 钩子类型：A新人物 / B新信息 / C新危险 / D新奖励 / E新选择 / F身份反转 / G认知反转 / H更大问题
- 误判或失败：没有就写「无」

## 约束
- N 必须与输入章号一致
- 每条一句话
- 原句摘录不超过 80 字，并标明章号
- 禁止对话场面，禁止续写情节
- 钩子类型必须八选一
- 失败必须写带走了什么新问题
